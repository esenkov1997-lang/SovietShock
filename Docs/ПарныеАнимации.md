# Парные анимации (игрок ↔ враг)

Анимации, где игрок и враг взаимодействуют физически: собака вцепляется в руку, враг валит с ног, добивание и т.п. Первый рабочий пример — **захват собаки** (`DogGrab` + `PlayerDogGrab`).

---

## Как это работает

1. **В Blender** игрок и враг анимируются **в одной сцене, вместе** — как будто их снимают одной камерой.
2. **В игре** перед началом враг **подтягивается** в ту же позицию относительно игрока, что была в Blender (≈0.25 сек), а игрок разворачивается к нему.
3. Оба клипа **стартуют в один кадр** и играют синхронно.

Главная «стыковочная» информация — **смещение врага относительно игрока**: сколько метров вперёд, вбок и на сколько градусов развёрнут. Его записываешь из Blender и вписываешь в Unity.

> Новый захват = **новый ассет настроек + 2 клипа**. Код писать не нужно.

---

## 1. Blender — сцена взаимодействия

### Игрок (руки)

- Отдельная сцена/файл для взаимодействия. **Анимации оружия не трогать** — у них своё соглашение (root рига = точка камеры).
- Объект **Armature рук — в нулях**. Это **ступни игрока**.
- **В экшене взаимодействия** (только в нём!) root-кость рук поднята так, чтобы **CameraBone была на высоте 1.7 м** — это высота глаз игрока в игре.
- Руки — тот же риг FPHands (те же имена костей), что у оружия.
- **CameraBone = настоящая камера** игрока во время анимации: рывки, взгляд вниз, наклоны — игрок увидит ровно то, что поставлено.
- **Root игрока не двигать** — игрок стоит на месте.

### Враг

- Объект **Armature врага** (Object Mode, **без ключей!**) сдвинуть и развернуть так, чтобы он стоял перед игроком как нужно.
- **Root-кость врага** анимируется как обычно — относительно своей стартовой точки (рывок, отскок — через root).
- ❗ Смещение **нельзя** ставить ключами на root-кость: Unity берёт из root только изменения, стартовая позиция потеряется.

### Запиши смещение

| Что | Пример |
|---|---|
| Сколько метров **вперёд** от игрока стоит враг | 1.1 |
| Сколько метров **вбок** (вправо +, влево −) | 0 |
| На сколько **градусов** развёрнут | 180 (мордой к игроку) |

### Требования к клипам

- **Одинаковый FPS** (30) у обоих, старт с **кадра 0**.
- **Первый кадр камеры** — взгляд прямо (или чуть вниз): код считает его «взглядом прямо» и плавно подводит к нему текущий взгляд игрока.
- **Клип игрока** заканчивается, когда руки ушли из кадра — в этот момент игроку возвращается управление. Может быть короче клипа врага.
- **Клип врага** — целиком: захват → удержание → отпускание → отскок → **последний кадр = поза Idle** из Blend Tree.
- Резать клип врага на части нужно, только если будут разные концовки (QTE «вырвался / не вырвался») или кусок будет переиспользоваться.

### Экспорт

1. Врага: **Alt+G** и **Alt+R** (сбросить позицию и поворот Armature) → экспорт FBX → **Ctrl+Z** (вернуть сцену).
2. Руки: экспорт как обычно.

## 2. Unity — импорт

### Клип врага (вкладка Animation у FBX)

| Настройка | Значение |
|---|---|
| Loop Time | ❌ |
| Root Transform **Rotation** → Bake Into Pose | ✅ (❌ если враг разворачивается корпусом в клипе) |
| Root Transform **Position Y** → Bake Into Pose | ✅ |
| Root Transform **Position XZ** → Bake Into Pose | ❌ (рывок/отскок реально двигают врага) |
| **Events** | `GrabBite` — на каждый кадр «сжатия». Каждое событие = урон |

Нажать **Apply**.

### Клип игрока

- Loop Time ❌. Больше ничего.

### Animator Controller врага

- Перетащить клип в окно → состояние с именем, как в ассете настроек (например, **`DogGrab`**).
- Поле **Tag** состояния: **`Grab`**.
- Переход **DogGrab → Blend Tree**: ✅ Has Exit Time (~0.95), без условий.
- **Переходы В состояние не нужны** — код запускает его сам по имени.

## 3. Unity — сборка

### Ассет настроек

**ПКМ → Create → Enemies → Synced Attack**

| Поле | Что вписать |
|---|---|
| Enemy State Name / Tag | имя и тег состояния врага (`DogGrab` / `Grab`) |
| Player Clip | клип игрока (раскрыть FBX стрелкой) |
| Forward / Side / Yaw Offset | смещение из Blender |
| Damage Per Bite | урон за каждое `GrabBite` |
| Chance | шанс захвата вместо обычной атаки. **Для теста — 1**, потом ~0.3 |
| Cooldown | пауза между захватами |
| Max Angle From Player View | захват только спереди (враг в пределах этого угла от взгляда игрока) |
| Required Space Behind | сколько места нужно за врагом для отскока |
| Camera Blend In / Out | плавность перехода камеры в анимацию и обратно |
| Player Arms Yaw Offset | если руки оказались позади/сбоку — 180 / ±90 |
| Player Height Offset | ручная подстройка высоты рук (м), если руки чуть выше/ниже, чем в Blender |

### Компоненты

- **Враг (корень):** `EnemySyncedAttack` → перетащить ассет настроек.
- **Игрок (PlayerCapsule в префабе Player):** `PlayerSyncedAnimation` → Arms Prefab = **InteractionArms**.

### Префаб InteractionArms (один на все взаимодействия)

- Модель `FPHands.fbx` → в сцену.
- **Animator:** Avatar = аватар FPHands, Controller — пусто, Culling Mode — Always Animate.
- **Layer: Default** (не слой оружия!) — чтобы зубы врага перекрывали руку, а не рука рисовалась поверх врага.
- Сохранить в `Assets/Player/Prefabs`.

## 4. Когда захват НЕ срабатывает (это нормально)

Вместо захвата будет обычный укус, если:

- игрок **в приседе**, в воздухе, у терминала, залезает на уступ;
- враг **не перед игроком** (вне угла Max Angle From Player View);
- **разница высот** больше допуска (лестница, ящик);
- в точке стыковки **нет NavMesh** или **за врагом нет места** для отскока;
- не выпал **шанс** или идёт **кулдаун**;
- включён отладочный режим «враги не атакуют» / «не замечают».

## 5. Частые проблемы

| Проблема | Решение |
|---|---|
| Руки позади или сбоку | Player Arms Yaw Offset = 180 / ±90 |
| Руки чуть выше или ниже, чем в Blender | Player Height Offset (+ выше, − ниже). Руки и так ставятся на пол под врагом — точка отсчёта игрока в Unity на ~11 см выше пола |
| Зубы не попадают в руку | подправить Forward / Side Offset на пару сантиметров |
| Рука обрезается у самой камеры | PlayerFollowCamera → Lens → **Near Clip Plane** = 0.05 |
| Камера резко входит/выходит | Camera Blend In / Out в ассете |
| В консоли «нет состояния …» | имя состояния в контроллере ≠ Enemy State Name |
| В консоли «не перешёл в состояние захвата» | не заполнен **Tag** у состояния |
| Враг «улетает» или съезжает в начале | Armature врага не сброшен перед экспортом (Alt+G / Alt+R) или смещение поставлено ключами на root |
| Враг не отскакивает | Position XZ в клипе врага «запечена» — снять галку |
| Камера смотрит не туда в начале | первый кадр CameraBone в клипе — не «взгляд прямо» |
